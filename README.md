# प्रगणक सर्वेक्षण ऐप (Offline Census PWA & Supabase Sync)

यह ऐप भारत सरकार के **"परिवार प्रपत्र" (Census Household Schedule - Q.1 से Q.40)** के आधार पर तैयार किया गया है। यह Android मोबाइल पर **100% ऑफ़लाइन** काम करता है और इंटरनेट मिलने पर **Supabase** में ऑटो-सिंक हो जाता है।

---

## मुख्य विशेषताएं:

1. **लोकेशन स्मार्ट-लॉक:** राज्य, जिला, ब्लॉक, गाँव का नाम व कोड एक बार सेटिंग्स में सेट होगा, हर फॉर्म में अपने-आप भरा रहेगा।
2. **गांव के 3 सेक्शंस:** स्क्रीन पर सबसे ऊपर `[सेक्शन 1] [सेक्शन 2] [सेक्शन 3]` का त्वरित स्विच।
3. **गतिशील व संपादन योग्य संख्याएं:**
   - **भवन संख्या:** direct edit + `[-1]` `[+1]` बटन।
   - **मकान संख्या:** direct edit + `[-1]` `[+1]` बटन।
   - **परिवार संख्या:** **पूर्णतः संपादन योग्य (Fully Editable)** + प्रत्येक परिवार सेव होते ही ऑटो-इन्क्रीमेंट (001 -> 002 -> 003)।
4. **सुपर-फास्ट थंब-फ्रेंडली डिजाइन:**
   - सभी कोड्स (01-32 संबंध, 1-5 वैवाहिक स्थिति, 1-7 धर्म, शिक्षा, कार्य) के लिए बड़े टच बटन (ड्रॉपडाउन का झंझट खत्म)।
   - **मुखिया से ऑटो-कॉपी:** 1 क्लिक में धर्म, जाति, और स्थायी पता परिवार के सदस्यों में भर जाता है।
   - **कंडीशनल स्किप लॉजिक:** 7 वर्ष से छोटे बच्चों के लिए शिक्षा/काम गायब, पुरुषों के लिए प्रजनन प्रश्न गायब, अविवाहितों के लिए शादी के प्रश्न गायब।
5. **0.01 सेकंड ऑफ़लाइन सेविंग (IndexedDB):** बिना इंटरनेट के फोन की मेमोरी में बिजली की तेजी से सुरक्षित।
6. **Excel डाउनलोड:** बिना इंटरनेट के भी सीधे मोबाइल/लैपटॉप में पूरी `.xlsx` फाइल डाउनलोड करने की सुविधा।

---

## 1. Supabase में डेटाबेस तैयार करना (2 मिनट का काम)

1. [Supabase](https://supabase.com) पर फ्री अकाउंट बनाएं और एक नया प्रोजेक्ट बनाएं।
2. बाएं मेन्यू से **SQL Editor** खोलें।
3. `supabase_schema.sql` फाइल का पूरा कोड कॉपी करके SQL Editor में पेस्ट करें और **Run** दबाएं।
4. **Project Settings -> API** में जाएं और:
   - **Project URL**
   - **anon / public key**
   को कॉपी कर लें।

---

## 2. ऐप चलाना

अपने कंप्यूटर/लैपटॉप के टर्मिनल में रन करें:

```bash
npm run dev
```

यह आपको एक लोकल लिंक देगा:
`http://localhost:3000` और साथ में नेटवर्क IP जैसे `http://192.168.1.X:3000`।

---

## 3. मोबाइल पर कैसे चलाएं (Android PWA)

1. अपने लैपटॉप और मोबाइल को एक ही वाई-फाई या मोबाइल के **हॉटस्पॉट** से कनेक्ट करें।
2. मोबाइल के **Chrome Browser** में नेटवर्क IP खोलें (उदा. `http://192.168.1.X:3000`)।
3. Chrome के मेन्यू (तीन डॉट्स) में जाकर **"Add to Home Screen" (होम स्क्रीन पर जोड़ें)** दबाएं।
4. अब आपके फोन पर यह एक **असली ऐप** की तरह इंस्टॉल हो जाएगा!
5. **फील्ड में जाने से पहले:** ऐप के सेटिंग्स (गियर आइकन ⚙️) में जाकर गाँव की लोकेशन और Supabase की Keys भर दें।
6. अब आप फील्ड में इंटरनेट बंद करके भी दिनभर डेटा कलेक्ट कर सकते हैं। शाम को नेट चालू करके **"सिंक"** बटन दबाएं — सारा डेटा Supabase में पहुंच जाएगा!
